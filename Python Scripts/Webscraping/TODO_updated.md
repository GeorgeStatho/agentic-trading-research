# Webscraping Public Notes

The public repository intentionally shows only a demo-safe scraping framework.

Current public goals:

- preserve the planner -> crawler -> normalization -> downstream analysis architecture
- provide generic Scrapy and Playwright examples
- keep sample output and mocked tests available for contributors

Out of scope for the public branch:

- production feed mappings
- source-specific extraction rules
- private ranking and deduplication heuristics
- bypass or anti-block behavior
